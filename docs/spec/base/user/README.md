# ユーザ機能

WEKO3 のエンドユーザー向け機能仕様。機能グループは以下の通り。

| グループ | カテゴリ | 主な機能（ファイル） |
| --- | --- | --- |
| 1_x | 検索 | 簡易検索(1_1)、詳細検索(1_2)、インデックス検索(1_3)、ファセット検索(1_4)、RSS(1_5) |
| 2_x | 一覧・表示 | 一覧形式表示(2_1)、目次形式表示(2_2)、雑誌情報(2_3)、アイテム一括出力(2_4) |
| 3_x | アイテム詳細 | メタデータ表示(3_1)、コンテンツファイル管理(3_2, 3_2_1)、バージョン管理(3_3)、引用情報(3_4)、統計情報(3_5)、共有(3_6)、エクスポート(3_7)、Google Scholar/Dataset メタデータ出力(3_8, 3_9)、所属コミュニティ表示(3_10)、リクエスト機能(3_11)、メールアドレス入力(3_12)、アイテム利用申請(3_13) |
| 4_x | ワークフロー・アイテム登録 | アクティビティ/ワークフロー一覧(4_1, 4_2)、ワークフロー(4_3)、Item Registration一式(4_4〜4_9, 4_16, 4_17)、Identifier Grant(4_10)、Item Link(4_11)、OA Policy Confirmation(4_12・現在非対応)、Approval(4_13)、メール入力/End画面(4_14, 4_15) |
| 5_x | コミュニティ | コミュニティ(5_1)、コンテンツポリシー(5_2) |
| 6_x | ランキング | ランキング(6_1) |
| 7_x | 共通機能 | ファイルアップロード(7_1)、言語切替(7_2) |
| 8_x | アカウント・認証 | サインアップ(8_1)、ログイン(8_2)、パスワードリセット(8_3)、ユーザープロファイル設定(8_4)、API設定(8_5) |
| 9_x | Cookie | Cookie使用確認画面表示(9_1) |
| 10_x | ワークスペース | アイテム一覧情報取得(10_1)、簡易アイテム登録(10_2)、メタデータ自動補完(10_3) |
| 11_x | 外部連携 | researchmap連携機能(11_1) |

> 認証系（8_1〜8_3）の画面・エラー文言は依存ライブラリ Flask-Security（`SECURITY_MSG_*`）に由来する。
