### インデックス検索用API

  - 目的・用途

インデックスIDを指定しての検索機能を提供する。

  - 利用方法

| **Method** | **HTTP request**   | **Description** |
| ---------- | ------------------ | --------------- |
|            | **GET /api/index** | アイテムを検索する       |

クエリパラメータ

| **GET /api/opensearch/search** |    |     |             |
| ------------------------------ | -- | --- | ----------- |
| パラメータ                          | 必須 | 値   | 説明          |
| q                              | 〇  | int | インデックスIDを指定 |
