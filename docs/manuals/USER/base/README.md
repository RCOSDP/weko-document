## はじめに

このマニュアルは、WEKO3システム（以下、システムと称す）の操作方法を説明したものです。データの登録、参照などを行うユーザが参照してください。

  - 対象読者

システムを操作する次の方を対象としています。

  - データを閲覧する一般閲覧者

  - データを登録・編集する登録ユーザ

  - データを登録するコミュニティ管理者、リポジトリ管理者およびシステム管理者

## システムの概要

この章では、システムの概要について説明します。

### システムとは

システムを使用すると、学術成果を保管して公開することができます。このシステムのリポジトリには、PDFファイル、動画、画像などさまざまな形式のコンテンツを保管できます。また、研究成果を分かりやすく管理できるように、保存した学術成果を分類してツリー形式で表示したり、研究成果を参照する際にもキーワードや全文検索などで探したりすることができます。また、リポジトリは、ほかのリポジトリともデータを同期させることができます。アイテムやインデックスなどの用語の意味については、「1.2用語解説」を参照してください。

![](media/media/image1.png)

図 1-1 システムのデータ管理

アイテムを登録する場合、データ登録者はワークフローを作成してアイテムを登録し、査読者や承認者の承認を経てデータを登録・公開をします。

### システムの機能

システムの機能を次の表に示します。

表 1‑2システムのデータ登録・閲覧に関する機能

| 機能          | 説明                                                                                              |
| ----------- | ----------------------------------------------------------------------------------------------- |
| アイテム一覧表示    | システムに登録されているアイテムを一覧で表示できます。一覧から選択されたアイテムの詳細情報を表示します。                                            |
| アイテム詳細表示    | アイテムのメタデータを表示できます。また、アイテムを構成する研究データのファイルをダウンロードできます。                                            |
| ランキング表示     | アイテムの参照回数などの統計情報を集計して、ランキングを表示できます。                                                             |
| インデックスツリー検索 | インデックスツリーのインデックス名を選択して、インデックス名に属するアイテムを一覧表示できます。                                                |
| キーワード検索     | キーワードを指定してアイテムの検索ができます。検索結果は、キーワードを含むアイテムを一覧表示します。検索対象は、アイテムのメタデータとコンテンツファイルです。                 |
| アイテム登録・公開   | 研究データや関連する資料、論文等を登録して、公開することができます。コンテンツファイルとそのメタデータは、アイテムという単位でリポジトリに登録されます。メタデータのみ登録することもできます。 |
| ワークフロー      | アイテムを登録するときにワークフローを設定し、査読・承認、そして公開という段階で処理します。承認待ちとなっているアイテムを一覧表示することもできます。                     |
| アイテム編集・削除   | いったん登録したアイテムの編集や削除ができます。                                                                        |

### 異体字検索について

意味と読みは同一であるが表記に差異のある語句による検索、いわゆる「異体字検索」をサポートしています。

例として、タイトルの検索キーワードとして「壱」を入力し、検索を実行したとき、「壱」の異体字である「一」などを含むアイテムも検索することができます。

注

日本語だけをサポートしています。英語での異体字検索は出来ません。

異体字のインデックス定義はNACSIS-CATの漢字統合インデックスを用いており、インデックス定義は下記サイトより取得可能です。

\[漢字統合インデックス提供に関するガイドライン\]  
https://www.nii.ac.jp/CAT-ILL/about/system/kui.html

##### 「Import to GakuNin RDM」ボタン

この機能は、WEKO3で公開されているGakuNin RDMプロジェクトアーカイブを、GakuNin RDMに新しいプロジェクトとしてインポートするためのものです。GakuNin RDMプロジェクトアーカイブはGakuNin RDM上でプロジェクトをエクスポートすることで作成されます。

手順は以下の通りとなります。

1. GakuNin RDMでプロジェクトをエクスポートします。
2. WEKO3のアイテム個別登録画面からエクスポートしたファイル（GakuNin RDMプロジェクトアーカイブ）をアップロードします。
3. MIME Typeが「application/zip」となるため「application/rdm-project」に変更します。
4. ファイルのアクセスを「Open Access」または「Input Open Access Date」のいずれにかにします。
5. 以上で、GakuNin RDMプロジェクトアーカイブの公開準備が整いました。
6. アイテム詳細画面の当該ファイルに「Import to GakuNin RDM」ボタンが表示されます。アイテムが公開されていて、ファイルが公開されている（「Input Open Access Date」の場合は公開日を過ぎている）場合は、ボタンをクリックするとGakuNin RDMに移動してアーカイブをインポートできます。それ以外の場合はボタンが無効の状態で表示され、ボタンにマウスポインターを合わせると理由（「アイテムが公開されていません」「ファイルが公開されていません」「アイテムとファイルが公開されていません」のいずれか）が表示されます。なお、このボタンは［ダウンロード］ボタンと同じ条件で表示されます。制限公開のファイルで利用申請が承認されていないなど、［ダウンロード］ボタンの代わりに［申請］ボタンが表示される場合は表示されません。

#### リクエストメール送信フォーム

本機能は、試験的な機能です。JAIRO Cloud環境で提供しておりません

> アイテム詳細画面の「Request Mail」ボタンを押下することで、リクエストメール送信フォームが表示されます。

> リクエストメールは、そのアイテムの作成または編集時にリクエストメール送信先として設定されたメールアドレスに送信されます。

> リクエストフォーム上では、以下の項目の入力が可能となります。

> - From  
  > この項目は、送信者のメールアドレスを入力する項目となります。  
  > メールアドレスの形式が不適切である場合は、送信ボタン押下時に、エラーメッセージが出力されます。  
  > 入力必須項目となります。

> - 件名（Subject）  
  > この項目は、メールの件名を入力する項目となります。  
  > 入力必須項目となります。

> - 本文（Message）  
  > この項目は、メールの本文を入力する項目となります。  
  > 入力必須項目となります。

> 上記項目を入力後に、表示されているCAPTCHA画像の計算結果をフォーム右下の入力欄に入力していただくことで送信が可能となります。

> CAPTCHA画像には有効期限が設定されてます。

> 有効期限が切れていた場合はメールの送信を行うことができず、画像が更新されます。デフォルトの有効期限は600秒となります。

#### 外部データ利用申請

本機能は、試験的な機能です。JAIRO Cloud環境で提供しておりません

> アイテム詳細画面右側にある「申請」ボタンを押下することで、WEKO外部にあるデータの利用申請ができます。

> - 本機能は、以下の条件をすべて満たしている場合にのみ利用できます。

> - コンテンツファイルが登録されていない。

> - アイテムの利用申請方法が設定されている。

> 1.  ［申請］ボタンを押下すると、利用規約を設定している場合、利用規約がモーダル画面に表示されます。

> 利用規約文表示エリア下部にチェックを入れることで、［次へ］ボタンを押下することができます。ボタンを押下すると、メールアドレス入力のモーダル画面を表示します。

> また\[利用規約を印刷\]ボタンを押下することで、表示されている利用規約を印刷するための印刷プレビューを開くことができます。

> ![](media/media/image99.png)

> 2. モーダル画面で指定したメールアドレスに特定のワークフローの編集画面リンクを含めたメール文を送信します。受信したメール文のリンクをクリックするとワークフローに定義されているアクション画面（アイテム登録画面など）に遷移して、ワークフローを登録して終了まで操作できます。

> 起動したワークフローが「作業済(Done)」になった際、ワークフローを起動したユーザーにファイルのダウンロードリンクをメールで送信します。

> なお、提供方法に一致しないユーザーが［申請］をクリックした場合は管理者が設定している警告メッセージをモーダルで表示します。

> メールで送られたリンクからコンテンツファイルのダウンロードをした際に、ユーザーのアカウントに応じた利用報告ワークフローリンクをメールで送信します。

> - ゲストユーザーの場合: アクセス期限のある利用報告ワークフローのアクセスリンクをメールで通知します
> - アカウント登録済ユーザーの場合: 制限のない利用報告ワークフローのアクセスリンクをメールで通知します

#### ファイルを公開バケットへコピーする
該当のファイルを、Amazon S3等の公開バケットへコピーする機能です。  

注：本機能は、設定ファイル（instance.cfg）で `WEKO_RECORDS_UI_USER_STORAGE_MODIFICATION_ENABLED = True` が設定されている場合にだけ利用できます（既定の設定は無効（False）です）。無効の場合、［公開バケットへコピー］ボタンおよびプロフィール画面のS3アカウント情報の項目は表示されません。

1.  コピー先のバケットを取得/作成するために、  
    プロフィール情報にS3のアカウント情報設定が必要になります。  
    設定画面は画面右上のアカウント欄「▼」ボタン→「プロフィール」から開けます。  
    使用するS3アカウント情報を元に図の「6」～「9」の項目を設定してください。  
    （項目「8」：入力例「https://s3.{リージョン名}.amazonaws.com/」）  
![](media/media/image273.png)  
図 433 プロフィール画面

2.  アイテムの編集権限があるアカウントでファイル詳細画面を開いた場合、  
    ファイル名情報欄に「公開バケットへコピー」ボタンが表示されます。  
![](media/media/image331.png)

##### researchmap からメタデータを自動入力する

researchmapからメタデータを自動で入力する手順を説明します。

1.	Select the IDでresearchmapを選択します。
［メタデータの自動入力］画面が以下のようになります。

![researchmapの情報入力画面](media/media/image140.png)

2.	parmalink、業績種別、業績IDを入力します。

ⅰ. parmalink

parmalinkとは、researchmapでの新規登録の際にご入力いただくリンク識別子のことを言います。「マイポータル」（researchmapの公開用ウェブページ）にアクセスするための研究者詳細ページURL末尾に付く文字列です。英数字記号混合で3～20文字で構成されており、以下の文字を含む場合、エラーとなります。

・使用不可文字
% # < > + ¥ " ' & ? = ~ : ; , @ $ ^ | ] [ ! ( ) * /

ⅱ. 業績種別

業績種別は、以下の6種に対応しています。
　論文、MISC、書籍等出版物、講演・口頭発表等、Works（作品等）、その他
デフォルトでは、「論文」が設定されています。

ⅲ. 業績ID

業績IDとは、researchmapに登録されている業績を特定するIDです。数字以外の文字を含むとエラーとなります。
上記ⅰ～ⅲのURL構成は、以下のようになります。

　https://researchmap.jp/{parmalink}/{業績種別}/{業績ID}

3.	[取得]ボタンをクリックします。
入力した情報に誤りがない場合、メタデータが自動入力されます。

#### CRIS連携機能(researchmap連携機能)

researchmap連携を行う手順について説明します。

1. researchmapの左部にあるチェックボックスにチェックを入れます。

　researchmapの下部には、連携結果が表示されています。表示結果は以下の4種となっています。

　ⅰ. なし：一度も連携が行われていない状態を指します。

　ⅱ. Running：WEKO上での操作を終え、CRIS機関との連携を待機または行っている状態です。

　ⅲ. 成功：CRIS機関との連携に成功した状態です。完了した日付も表示されます。

　ⅳ. 失敗：CRIS機関との連携に失敗した状態です。失敗した日付も表示されます。

2. チェック後、当該ワークフローを完了します。

ワークフロー完了時に、自動連携が予約されます。

連携対象の著者に関しては、アイテムに入力してある著者（Creater,Contributer）を対象にします。
連携には事前に著者DBにparmalinkを登録しておく必要があります。

また、自動連携が行われるタイミングはデフォルトで毎日0時となっています。

![CRIS機関との自動連携](./media/media/images356.png)

（補足）researhmapとの連携を行う際には、以下のメタデータが必須項目となります。



必須メタデータ一覧

|jpcoar_mapping|メタデータ名|
|---|---|
|dc:title|タイトル|
|jpcoar:creator|作成者*1|
|datacite:date|日付*2|

*1：作成者は、著者DBに登録されておりresearchmapのparmalinkが設定されている作成者を指定する必要があります。

*2：アイテムの公開日とは異なる項目なので、別途設定が必要となります。

#### アイテムを承認する

アイテムを承認できるのは、基本的にリポジトリ管理者のロール権限を持つユーザーです。

リポジトリ管理者以外が承認できる場合は以下が存在します。

- 承認者に特定のロールが設定されていた場合：選択されているロールのユーザーが承認することができます。

- 承認者に特定のユーザーが設定されていた場合：選択されているユーザーが承認することができます。

・以下の事例は、＜利用申請機能 先行利用機関＞のみ利用可能です。当機能の先行利用を申請していな機関は、利用できません。

> - 承認者にプロパティが設定されていた場合：選択されているプロパティに設定されているユーザーが承認することができます。

> - 承認者に「アイテム登録者」が設定されていた場合：アイテムを登録した本人が承認することができます。

・以下の事例は、試験的な機能です。JAIRO Cloud環境で提供しておりません

> - 承認者に「リクエスト送信先」が設定されていた場合：アイテム登録の際に設定する「リクエスト送信先」のメールアドレスで登録しているユーザーが承認することができます。
> - 承認者が「リクエスト送信先」かつ、制限公開アイテムに対する「利用申請」、「二段階利用申請」ワークフローの場合：「利用申請の対象となった制限公開アイテムのリクエスト送信先のメールアドレス」のユーザーが承認することができます。

なお、承認者の設定方法はシステム管理マニュアルの「8.1フローを設定する」を参照してください。

登録者の承認待ちである登録するアイテムに対し、「却下(Reject)」、「保存(Save)」、「承認(Approval)」を行うことができます。

制限公開アイテムに対する「利用申請」、「二段階利用申請」ワークフローでの承認の際は、申請時に登録されたアイテムの表示形式に関係なくプレビュー機能が表示されます。

こちらの機能は、管理画面にてON/OFFの切り替えを行うことができます。

### 非公開コンテンツをワンタイムアドレスを利用して共有したい

#### シークレットURL機能
<p>管理者画面でシークレットURL機能を有効化することで、シークレットURLを発行することができます。<br>
シークレットURLとは、投稿者（代理投稿者を含む）及びシステム、リポジトリ管理者が発行できるワンタイムアドレスであり、このURLを知っている人は、誰でも対象のコンテンツファイルをダウンロードできます</p>

**<span style="color: red; ">本機能は、公開コンテンツ、ならびにサイトライセンス機能を利用してサイトライセンスユーザーに対してアクセス可能になっているコンテンツに対して、新たにアクセス権限を付与し、シークレットURLを通じたアクセスに制限する機能ではありません<span>。**

 Information画面のファイルエリアに「Secret URL」ボタンが追加されるのは、以下の条件を満たした場合となります。
 
 1.管理画面の制限公開画面にて、シークレットURLの表示を有効化している。
 
 2.アイテム投稿者・アイテムの代理投稿者・リポジトリ管理者・システム管理者がログインしている。

 3.当該ファイルを「公開しない」と設定している。または、ファイルが「オープンアクセス日を指定する」と設定し、指定日が未来日である。

 注：アイテムの登録先インデックスが「公開」であること、およびアイテムのPublish Statusが「Public」であることは、ボタンの表示条件ではありません。これらはシークレットURLからのダウンロード時に確認され、満たさない場合はシークレットURLからダウンロードできません。

### アイテム簡易登録

この章では、ワークスペースのアイテムの登録について説明します。

1.  アイテム一覧のアイテム登録ボタンをクリックするとアイテム登録画面に遷移します。
2.  【v2.1.0】[DOI入力]欄にDOIを入力し、[取得]ボタンをクリックします。CrossRef、JaLC、CiNii、DataCite、arXivの各取得元からメタデータの取得を試み、取得できた取得元のラジオボタンが選択可能になります。
3.  【v2.1.0】メタデータの取得元（CrossRef MetaData、JaLC MetaData、CiNii MetaData、DataCite MetaData、arXiv MetaData）をラジオボタンで選択すると、取得できたメタデータが自動で入力されます。
4.  [ファイルを選択]ボタンをクリックすると、ファイルをアップロードできます。
5.  インデックスを選択し、登録ボタンをクリックするとアイテムが登録できます。
