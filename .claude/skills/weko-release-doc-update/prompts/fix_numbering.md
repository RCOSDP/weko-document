# 手順番号・節番号参照の修正
日本語版マニュアル `{{MANUAL_PATH}}` の次の誤りを直す（このファイルだけ編集）。
1. 崩れた手順番号：Word 変換の名残で節をまたいで通し番号になっている手順を、各手順 1 から振り直す。途中に画像・説明・`<!-- end list -->`・表が挟まっても同じ手順なら続き番号。実際に長い手順は変えない。番号の参照（「手順3で」）も合わせる。インデント構造は変えない。
2. 節番号の参照：本文の「「N.N 節名」を参照」で、番号・節名が目次と合わないものを目次に合わせる。他マニュアルの節は、そのマニュアルの目次に合わせ「ユーザ操作マニュアルの」等と分かる書き方に。目次に無い小見出しは「「親の節」の「見出し名」」の形。旧通し番号での小見出し参照（「(5) ファイルを設定する」）も見出し名の参照に直す。
注意：見出し・目次は変更しない。タグは増減させない。番号と参照以外は変えない。
（取りまとめ役：先に目次の節名と一致するものは機械的に直し、同名の章と節（「アイテムを登録する」の 5 と 5.1）の取り違えに注意。残りを担当へ）
