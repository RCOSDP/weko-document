# 英語版マニュアル：未収録の章・節を日本語版から生成するルール

## 目的
英語版マニュアル（`/home/mhaya/weko-document/docs/manuals_en/ADMIN/admin_manual.md`、`docs/manuals_en/USER/user_manual.md`）に無い章・節を、
日本語版（`docs/manuals/ADMIN/base/README.md`、`docs/manuals/USER/base/README.md`。{{RELEASE_REF_NAME}} と突合済み・【{{NEW_VER}}】タグ付き）から英語で書き起こす。

## 作業の流れ
1. 担当の章・節が**本当に英語版に無いか**を、英語版ファイル全体を検索して確認する（英語版は見出し名が違ったり、`LINKID=...【参照先】` が付いていたり、別の章の中に入っていたりする）。一部だけある場合は、無い部分だけを生成する。既にある場合は生成しない。
2. 日本語版の該当部分を英訳した **Markdown の断片** を、担当ごとに指定されたファイル（`{{WORKDIR}}/en_frag/` 配下）に書き出す。**英語版マニュアル本体は編集しない**（差し込みは取りまとめ役が行う）。
3. 断片が複数の場所に入る場合は、場所ごとに別ファイルにする（例：`A3_1.md`、`A3_2.md`）。

## 各断片ファイルの先頭（必須）
1行目に、差し込み位置を示す HTML コメントを書く。
```
<!-- INSERT_BEFORE: <英語版マニュアル中に1回だけ現れる見出し行をそのまま> -->
```
または
```
<!-- INSERT_AFTER_SECTION: <英語版マニュアル中に1回だけ現れる見出し行をそのまま> -->
```
- `INSERT_BEFORE`：指定した見出し行の直前に入れる。
- `INSERT_AFTER_SECTION`：指定した見出しの節（同じかより上位の次の見出しの直前まで）の末尾に入れる。
- 見出し行は英語版ファイルからコピーし、ファイル中で一意であることを `grep -c` で確認すること（`LINKID` 付きの見出しもそのまま書く）。
2行目に `<!-- TOC: <目次に載せる番号と見出し。例: 3.7 Set up the JSON-LD mapping> -->` を、追加する見出しの数だけ並べる（目次に載せない小見出しは不要）。英語版の目次（Table of Contents）の既存の番号体系を見て、差し込み位置に合う番号を付ける。後続の番号の繰り下げは取りまとめ役が行うので、新しい見出しの番号だけを書けばよい。

## 英文の書き方
- 英語版の既存の章の文体・書式に合わせる（手順は番号付きリスト、項目説明は表、Notes は既存の書き方）。
- 見出しの階層は英語版の構成に合わせる（英語版は章が `#`、節が `##`、小節が `###`）。見出しに `LINKID` や `INDEXWORD` は付けない。
- 画面のラベル・ボタン名・メッセージは、日本語を直訳せず、英語 UI の実際の文言にする。{{RELEASE_REF_NAME}} のソース（`{{IMPL_SRC}}/modules/<module>/<pkg>/templates/`、`static/js/`、`translations/*/LC_MESSAGES/messages.po` の msgid）で確認する。英語版の既存の章で既に使われている訳語があれば、それに合わせる。
- 日本語版で【{{NEW_VER}}】タグが付いている段落・項目・表の行には、英訳の対応する位置に `[{{NEW_VER}}] ` を付ける（見出しには付けない。節ごと新規でタグが最初の段落だけに付いている場合も同じ扱い）。
- 未リリース機能の注記（大容量ファイルアップロード等）は、注記の意味をそのまま英訳する（タグは付けない）。
- **画像は付けない**（日本語版のスクリーンショットは日本語 UI で、英語版の media フォルダとは番号も違うため）。画像の行は省き、「次の画面が表示されます」のような文は画像が無くても意味が通るように調整する。省いた画像の数は報告に書く。
- 表番号・図番号：英語版の章の番号体系（`Table 3-7` など）に合わせ、差し込み位置の章の既存の最大番号の続きを使う（同じ章に複数の担当が入る場合の衝突は取りまとめ役が調整する）。
- 日本語版内の章番号参照（「16.3 を参照」など）は、英語版の対応する節名への参照に置き換える（番号ではなく節名で書くとよい）。
- 実装と照らして日本語版の記述に誤りを見つけた場合は、英訳では実装どおりに書き、報告に挙げる（日本語版は編集しない）。

## 最終報告（30行以内）
1. 生成した断片ファイルと、それぞれの差し込み位置・目次項目
2. 英語版に既にあったため生成しなかった部分
3. 省いた画像の数、英訳で判断に迷った UI ラベル、日本語版の誤りと思われる点
